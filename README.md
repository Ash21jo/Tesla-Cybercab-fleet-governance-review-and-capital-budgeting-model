# Tesla-Cybercab-fleet-governance-review-and-capital-budgeting-model
Excel model and report assessing a US$2.55bn, 60,000-vehicle Tesla Cybercab fleet. Covers Tesla's governance, cost of capital (WACC 18.29%), cash flows valued by WACC, APV and FCFE (NPV -US$504m, IRR 11.03%), plus scenarios, Monte Carlo, sensitivity and break-even analysis. Recommendation: reject under current assumptions.
